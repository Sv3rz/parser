Сайт - парсер данный с платформы alot.pro



Как запустить сайт?

Сайт запускается через панель panel.bat.
Чтобы запустить сайт нужно:
1) Открыть panel.bat
2) Выбрать 2 пункт "Запустить / остановить сайт"
3) Перейти по ссылке на сайт.

Сайт выполнен в учебных целях, для освоения работы с api различных платформ, не является коммерческой платформой и не был создан с целью кражи чужих данных
